# Laoreat API
The Laravel backend API for Laoreat, a university group project involving a mobile application and an admin dashboard

## Technologies
- Backend: PHP, Laravel
- Database: PostgreSQL
- Image Storage: Cloudinary
- Deployment: Render, Aiven

## Project Components
- **Backend API:** This repository
- **Admin Dashboard:** [laoreat-dashboard](https://github.com/Chonghok/laoreat-dashboard)
- **Mobile Application:** Developed collaboratively with the project team

## My Contribution
- Implemented backend functionality and API endpoints using Laravel
- Worked with PostgreSQL for application data
- Integrated Cloudinary for image storage
- Contributed to API integration with the mobile application and admin dashboard
- Deployed the backend API, database, and dashboard using Render, Aiven, and Netlify
